1. Inspect existing app, package, track status, upload certificate, account verification and production access. Google Play's August 2026 target requirement is API 36. For applicable personal developer accounts established after 13 November 2023, closed testing requires at least 12 continuously opted-in testers for 14 days before applying for production access. Actual account requirement must be checked in Console.
2. Securely sign the exact release AAB with the existing upload key, not the debug key. Never put keys/passwords in GitHub source, chat or public artifacts. Use the already approved four DD_UPLOAD_* environment inputs in a secure signing environment; verify certificate fingerprint against Console. If no key has been established, configure Play App Signing with owner present; do not create a replacement key for an existing app.
3. Prepare store listing text, 512x512 icon, 1024x500 feature graphic, actual device screenshots (no mockups or claims beyond verified functionality), support email and privacy link. Complete app access directions; guest browsing does not require auth. Give reviewers a dedicated test account securely for member-only flows if required; never owner's account or private research.

Complete truthful Data safety, account deletion, content rating, app category, target audience, ads declaration, advertising ID and news/community declarations based on actual shipped build and backend/SDK data flow. Privacy policy: https://uapdisclosuredesk.com/privacy ; deletion URL: https://uapdisclosuredesk.com/privacy#account-deletion. ## Lifetime ad removal — proposed paid follow-up gate
- Google Play one-time, non-consumable product: remove_ads_lifetime, base UK price GBP 4.99, localised prices displayed by ProductDetails. No subscription, no consumption, no external Stripe payment for this digital feature.
- Existing LifetimeAdsManager is scaffolding only: local cache and client acknowledgement, not backend verified. PLAY_BILLING_APPROVED and PLAY_ADS_APPROVED remain false. Do not sell ad removal while ads are disabled. First configure product and test licensing privately. Implement trusted server-side Google Play Developer API verification, package/product/token matching, acknowledgement/retry, refund/revocation synchronisation and multi-device restore, without exposing credentials. Verify pending, cancelled, duplicate, offline, refund and restore paths. Set ad-free before loading eligible ads; test consent and privacy, suitable placement, ad-free status after refund, and accurate disclosures. No ads in private research or Chat. Third-party video ads excluded.
- Never require a purchase for free research features. No live purchases, real ad impressions, payments setup changes or production release performed by this build.
