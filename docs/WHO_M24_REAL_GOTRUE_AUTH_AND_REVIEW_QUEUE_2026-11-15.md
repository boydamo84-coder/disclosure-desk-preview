## Important distinction: tested Auth server vs connected production account

An ephemeral self-hosted GoTrue is the real Supabase Auth software and signs real tokens, but this test did not use the user's production project and is **not** a full hosted authentication-stack review: production signing keys/rotation, real account deletion, genuine password reset and email workflows, exposed schemas, revocation enforcement, cross-service permission grants, rate limiting and operational rollback still need separate controlled security signoff. No public rating is ready on the strength of local tests alone.
