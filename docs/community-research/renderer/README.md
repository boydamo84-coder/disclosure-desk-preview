# Offline PDF page representation — development only

Issue #18: keep the original PDF in **private** quarantine. A passing scanner result is not publication permission. This separate module makes an all-or-nothing *local candidate* only from a bounded source and internal scan receipt supplied by a trusted caller. It has no server/listener, public endpoint, credentials, original download, storage or database integration, or publication action. The fixture receipt in tests is fictional, not an official antivirus result. The renderer checks consistency (digest, original bytes, page count) but cannot authenticate a receipt; future orchestration must independently bind it to trusted scan output, reservation, account, exact source and final consent. Never accept a browser-supplied receipt as proof of scanning.

- Real Poppler (`pdfinfo`, `pdftoppm`) checks the page count, refuses encrypted PDFs or parser warnings, and renders one page at a time. Fixed max long edge 2,000 pixels. Crop box and orientation retained; interactive annotations suppressed. Output raw RGB raster is strictly bounded and re-encoded by Pillow into a fresh PNG. Only IHDR, consecutive IDAT and IEND are allowed, with checked dimensions, lengths and checksums. No source HTML, metadata, embedded file, interactive link, annotation stream or PDF bytes are copied into PNGs. Visible sensitive content in the page pixels is **not** removed; consent and takedown remain necessary.
- Preserve visual layout, not a byte-for-byte copy. Text in page images is not selectable or screen-reader-accessible; fonts/color representations may vary with the renderer. Future reader needs a properly accessible alternative, image zoom, a consent review of the exact representation, and explicit safe download policy. Original PDF remains private; do not serve it as a fallback. No OCR, accessible text extraction, or publication of metadata is implemented.
- 5 MB original and 1–100 pages. Renderer candidate has a separate hard **5,000,000-byte total** cap for every page PNG PLUS its private manifest, even if individual pages fit. This follows the existing conservative per-copy quota limit; image-heavy or long PDFs may be refused even when the original fits. No missing pages or silent quality reduction. Return complete candidate files and manifest only when all checks pass; otherwise return a bounded reason with no partial page/manifest data. Manifest binds ordered page files, dimensions, byte counts, SHA-256 digests and source digest. Reserve actual derivative bytes along with original in the 250 MB combined private ledger before any storage write; manifest and page files must all count. No actual storage reservation/write occurs here.
- Resource boundaries: overall rendering deadline 240 seconds, per-process bounded time, files, memory and CPU, non-root, no network, read-only rootfs, no mounted host paths/credentials, 64MB tmpfs, 1GB container memory, 2 CPUs, 64 pids in CI. Runtime target `renderer` contains no test script and has no listener. QA target creates fictional portrait/landscape reports and a high-entropy synthetic oversize fixture. QA verifies rendered table grid and coloured image pixels, dimensions, manifest and source immutability, metadata exclusion, digest/page count/size failure, malformed source, symlink/FIFO and actual 5 MB derivative cap. Visual review on local Poppler was performed separately. Restricted container exact-head CI is independent; verify results.
- No production release. Future serving must be separately approved (private source, no unauthorized storage access; verified immutable PNGs via narrowly scoped delivery bound to published state and withdrawal/flagging, MIME `image/png`, nosniff, no mixed-origin arbitrary HTML, no unapproved public URLs). Host capacity, supported/patched image build, scanner official signatures and separate process isolation, real receipt/orchestration, consent, storage accounting/reconciliation/deletion, public reader authorization, approved transport and strict release packaging remain gates. Do not bypass previously rejected publication operation, expose these fixtures, or relax the package allowlist. No new service or spend committed.
