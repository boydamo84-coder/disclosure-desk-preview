# Offline PDF quarantine inspector – development only

No listener, upload endpoint, storage client, publication credentials, DB access, or live member files. The fixed worker command reads a single private immutable object from a trusted orchestrator's read-only input volume, verifies the expected SHA-256 from the trusted reservation, and copies only bounded bytes into a private temporary directory. Worker stdout is a small machine-readable receipt; it never includes PDF content, original filename, scanner diagnostics or a download URL. The source is untouched. A clean result **does not authorize publication or mean malware-free**.

## Inputs and secure runtime

- 5,000,000 original bytes; 1–100 pages; finite bounded page dimensions. Plain PDF header and EOF only. No symlinks/FIFOs or digest mismatch.
- ClamAV: official-only main/daily/bytecode signature files mounted read-only at /signatures. Stale (>2 days), unavailable, partial, timeout, warning, skipped, extra/unexpected scan results, malware or scan-limit alerts fail closed. FreshClam is a separate admin-managed signature update process; never run it per upload. No external scanning API or document transmission.
- qpdf structural JSON v2 plus strict check with warnings rejected. Reject active actions, external streams, files, forms, encryption, unsupported annotations and unsafe URLs. HTTPS URI and internal GoTo links may exist but must remain inert in public rendering. Apply bounds on subprocess CPU/address space, output, object counts and temp files.
- Run only in an isolated restricted non-root container: no network, read-only root, no inherited service credentials, read-only source and signature mounts, only a bounded tmpfs, no host socket or other host paths, no extra privileges/capabilities, pids/memory/CPU/time caps. The example CI uses a 4GB memory cap; actual hosting capacity/concurrency/resource budget and patched image/version acceptance must be measured before selecting or provisioning a deployment host. Do not install on the existing LanguageTool VM until resource/security isolation and owner approval have been established.
- Production worker image target is `worker` (no test runner). Test image target is `qa`. CI runs the real installed ClamAV engine with an offline, harmless, synthetic hash signature and real qpdf against fictional PDFs; the official-only production entrypoint has no fixture override, and missing official databases block it. The CI fixture proves invocation and detection plumbing; production readiness still requires real up-to-date official signature verification and capacity acceptance. No malware samples or user documents.
- Retain input in private quarantine; separate service must enforce upload/account binding, atomic 250 MB aggregate reservation across quarantine/approved copies, expiry and removal, no public reads before technical approval. Next stage must safely render a public representation in a separately isolated renderer and bind its digest to the immutable scanned object and user consent. A clean original remains private until safe original/download delivery is reviewed. Do not relax the package allowlist or bypass any previously rejected publication transport.
