# Disclosure Desk project rules
1. Always read project continuity files and inspect existing source before changes.
2. No second W.NE Research Edition editor; integrate its established interface.
3. Keep the original W.NE repo, novel and live Disclosure Desk release untouched without explicit request.
4. Preserve existing Supabase accounts and `investigation_boards` table; apply row-level security and privacy by design.
5. Never use private user data for destructive testing; prefer separate synthetic test accounts and backup copies.
6. Do not publish every tiny change. Stage/test cohesive batches.
7. Separate established user-tested features from speculative roadmap ideas.
8. Update the handover at end of every development session.
